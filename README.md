# Partnerships Coordinator — Research & Outreach Repository

A centralized repository for researching, evaluating, and identifying potential content creators for brand partnerships and collaborations. This system helps streamline creator discovery, assess brand alignment, track potential opportunities, and organize outreach strategies to support effective and long-term partnerships.

See [REPOSITORY_STRUCTURE.md](REPOSITORY_STRUCTURE.md) for the folder map.

## System of record
- GitHub: brand knowledge, criteria, brand-voice examples, templates, SOPs, and learning notes.
- Google Sheets or equivalent: current creator leads, verified attributes, outreach status, follow-up dates, and results.
- Claude Project: analytical assistant using instructions and selected GitHub files. Claude does not automatically update the GitHub repository from a linked project.

## First pilot
Pirate Gold Poker gifting collaboration creator shortlist, using the exact assessment brief for deliverable details. Confirm current shipping availability and other brief requirements before outreach.

## Operating principles
1. Never invent creators, followers, locations, engagement numbers, emails, posts, or source links.
2. Mark every unverified item 'Needs verification', with a checked date and source link.
3. Start from the playbook templates, then personalize every message with a real, checked detail.
4. Never send messages or commit to terms without explicit human approval.
5. Use the company-approved tracking system; don't store confidential personal details unnecessarily.
